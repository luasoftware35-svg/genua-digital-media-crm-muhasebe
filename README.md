# Genua Digital — Ajans Yönetim Paneli

Şirket içi ajans paneli. Şu an **mock data** ile çalışır; Supabase bağlantısı sonra eklenecek.

## Çalıştır

```bash
npm install
npm run dev
```

Aç: [http://localhost:3000](http://localhost:3000)

Login: herhangi bir e-posta/şifre (demo).

## Modüller

- `/dashboard` — KPI, gelir grafikleri, aktiviteler
- `/firmalar` — CRM listesi + detay
- `/odemeler` — Faturalar, CSV export
- `/projeler` — Kanban (dnd-kit)
- `/teklifler` — Pipeline + win rate
- `/giderler` — Giderler + gelir/gider chart
- `/raporlar` — Aylık özet
- `/ayarlar` — Profil, ekip, hizmetler
